## 🎯 MARKING TECHNIQUE (how examiners give you full 5/5)

1. **Use the legend/symbols given** in the question paper — if it says ★ for cities, use ★.
2. **Label HORIZONTALLY, never vertically**, in pencil first; ink after checking.
3. **One item = one exact dot.** Never circle "approximately the whole state" — location, not outline, is marked.
4. **Underline the label**; if two sites are close (Delhi–Panipat, Hampi–Bidar), **use arrows**.
5. Write the **river names** (Yamuna, Tungabhadra, Ravi, Sutlej, Kaveri) where relevant — bonus credibility, sometimes a value point.
6. Attempt **all 5** — there is no negative marking; a wrong label costs nothing, a blank costs 1 mark.

## 🧠 MASTER MEMORY HACKS

- **Sufi sites — "A-D-S-P-M-G": Ajmer, Delhi, Sikri, Pakpattan, Multan, Gulbarga** → "**A Dosti Sada Pakki Mehfil Gaye**".
- **Mughal cities — "DAP AALG": Delhi, Agra, Panipat, Amber, Ajmer, Lahore, Goa** → "**DAP** (Delhi-Agra-Panipat triangle) then **AALG** westward".
- **Tungabhadra = T for Hampi (Twin-T). Yamuna = Y for Delhi & Agra (Yamuna-Yamuna twins). Ravi = Lahore, Sutlej = Pakpattan.**
- **Deccan Sultanates alphabet-south: "Bijapur–Bidar–Golconda" = B-B-G west→east.**
- Tamil cluster runs **north→south: Kanchipuram → Thanjavur → Tirunelveli** ("K-T-T = Kaveri To Tip").
