## 🧠 10 TIPS THAT ACTUALLY MOVE MARKS

1. **Weightage order is non-negotiable** — Theme 8 (15M) before everything. If the day collapses, you've already banked the biggest chapter.
2. **Skeletons, not essays** — practise 8-markers as intro-line + 5 bullet keywords + 1 conclusion. In the exam you only expand; the structure is pre-built.
3. **Quotes = source-based marks** — memorise 4–5 word fragments from each extract ("head of Brahman", "fruits of Khurasan", "as large as Rome", "one-third part... Royal dues").
4. **Dates on one card** — 973, 1017, 1336, 1509–29, 1565, 1580, 1595, 1604, 1761, 1800. Ten dates ≈ 6–8 MCQ marks.
5. **Traps you must pre-solve** — dawa = *foot* post (faster); Biruni = *hostage* (not envoy); Rihla dictated to *Ibn Juzayy*; Bernier served *Dara Shikoh*; Adi Granth = *1604, Guru Arjan*; Abdur Razzaq = *Persian ambassador*.
6. **Map twice, not once** — the 8:15 PM drill AND a 5-minute re-test tomorrow morning. Map memory decays fastest.
7. **Write, don't highlight** — highlighting feels productive and isn't. The red-pen error copy is your real syllabus by 9:40 PM.
8. **Answer format discipline** — every long answer: **Intro (1 line) → 5–6 sub-headed points with dates/terms (underlined) → Conclusion ("Thus...")**. Examiners pay for structure.
9. **Timer honesty** — if a block overruns, cut it and move on; the timetable already favours big chapters. Never sacrifice the 9:00 self-test — it's the highest-value hour.
10. **Morning-after 30 min** — tomorrow 7:00–7:30 AM: error copy + map re-drill + date card. This converts today's 7.5 hrs into exam-day recall.
